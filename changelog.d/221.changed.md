**CI and API docs odds and ends (Maestra fork, maestra-io/nora#221)** — the fuzz target `fuzz_config_toml`, which never parsed TOML, is `fuzz_validation_edges`, and no fuzz target is a test or a bench any more, so `cargo test --workspace` ends instead of running libFuzzer forever. The seven `/api/ui/*` endpoints the web UI calls are in the OpenAPI document. A non-blocking `bench build` job keeps the criterion benches compiling. The `s3 backends` suite pulls its MinIO client/server, SeaweedFS, Garage and Alpine images through packages.maestra.io with the job's OIDC token instead of from cgr.dev and Docker Hub directly.
