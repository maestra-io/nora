**apk and deb generation guards bound upstream times; deb subkeys honour primary expiry; alias suites (review R05, R11, R12, #291)** — an apk build time or a deb Release `Date` more than an hour past NORA's clock no longer orders index generations, so one such entry cannot refuse every later index. A deb signing subkey of an expired primary key no longer verifies an `InRelease`, as in gpgv. A Release that names no suite builds, as apt accepts it, and the new `deb.suite_aliases.<repo>` lists suites (Ubuntu `devel`) whose Release names another suite; any other mismatch is still refused.
