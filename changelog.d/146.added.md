**An upstream 401/403 logs the reason its body gives (issues-maestra#1649)** — a GitHub packages API refusal of a ghcr date lookup was logged as `Denied(403)` only (`ghcr.io/aquasecurity/node-collector`, 06.11 and 09.11), hiding the reason GitHub states. `ProxyError::Denied` now carries a JSON body's `message` with its `documentation_url` (body read up to 4 KiB), shown in `docker publish date lookup failed` and `upstream fetch failed`; any other body logs as before.
