**Authenticated answers are cached privately; cross-site browser writes are refused; HSTS on every response; the web-surface 401 is typed (audit A084, B07, B08, B10, maestra-io/nora#255)** — with auth on, every response to a request that can carry a credential had `Cache-Control: public` from its handler, so a shared cache in front of nora could have stored a hosted artifact and served it to a caller without one. The auth middleware now rewrites the `public` directive to `private` (max-age, immutable and must-revalidate stay) whenever auth is on and either `anonymous_read` is off or the request presented a credential or a curation bypass token; anonymous reads under `anonymous_read` keep `public`. The PyPI `/simple/` index and per-project pages, which answer HTML or PEP 691 JSON by `Accept`, now send `Vary: Accept`. A non-GET/HEAD/OPTIONS request whose `Sec-Fetch-Site` is `cross-site` or `same-site` is answered 403 `cross-site request refused` before any credential is checked: package clients send no `Sec-Fetch-*` headers and the same-origin UI sends `same-origin`, so only a browser-driven publish from another site is affected. Every response now carries `Strict-Transport-Security: max-age=31536000` unless the handler set its own (no `includeSubDomains`; browsers ignore it over plain http), mirrored in `deploy/Caddyfile`. The Basic challenge on the gated web surface and `/metrics` now has `Content-Type: text/plain; charset=utf-8`.
