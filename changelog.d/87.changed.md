**Digest-quarantine ledger in the storage backend (Maestra fork, maestra-io/nora#87)** — the ledger is one object per entry under `.nora-quarantine/<registry>/<digest>`, created with `put_if_absent` (first writer wins, also across replicas), plus a snapshot `.nora-quarantine-snapshot.json` that lets a start read one object and a listing instead of one GET per entry. A `{storage.path}/quarantine.jsonl` is imported at every start, keeping each `first_seen`. Before, the ledger was a file on the local volume, so `storage.mode = s3` still needed a PersistentVolume.
