**npm: concurrent requests for one packument read it once (maestra-io/nora#108)**. Each concurrent packument request used to read the whole stored upstream packument into its own buffer. 46 CI clients asking for `vite` (39 MB) at once held ~2.4 GB, and a CI wave OOMKilled the 4Gi pod on 2026-10-23. The cached read now goes through the single-flight map (key `cache-read:<key>`, metrics label `npm_cache`, off with `server.proxy_coalesce = false`). Only a successful read is shared. The install-v1 projection also parses only the fields it serves. Peak RSS for `vite` ×46 fell from 2359 to 463 MiB, and the response is byte-identical.
