**Go versions dated by proxy.golang.org's own first fetch (Maestra fork, `[go] attested_dates`)** — since #234 (A066) a Go version NORA had not cached before was refused for `min_release_age` from its first fetch, however old (sigs.k8s.io/e2e-framework v0.7.0, released April 2026, refused as "0h old"). With `[go] attested_dates` / `NORA_GO_ATTESTED_DATES=true` (default off; read only when `go.proxy` is `https://proxy.golang.org`, else ignored with a config warning) a version first seen inside the release age is dated `max(.info Time, min(zip Last-Modified, first sight))`: the zip's `Last-Modified` on proxy.golang.org is the proxy's own first fetch (the index.golang.org `Timestamp`), which the publisher cannot set, and the option only ever makes a date earlier. One HEAD per version through the `upstream_dates` memo on the `#dates` breaker, kept at `go/<module>/@nora-dates/<version>`; a pre-2019-04-10, missing or failed answer keeps nothing.
