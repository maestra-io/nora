**Config reload, publish cap and bypass answers (audit review R03, R10, R17)** — a SIGHUP on a start configured only by environment (no `config.toml`, as `dist/install.sh` installs) was refused since the A027 fix, so a changed blocklist or allowlist file applied only after a restart; the reload now refuses only a file that start read and that is gone or broken, and an env-only start reloads defaults + env as it started. A `publish_body_limit_mb` (bounded by `body_limit_mb`) above a non-zero `server.publish_inflight_mb` (default 2048) is cut to the budget; start now warns and names the effective cap. An answer to a request with `X-Nora-Bypass-Token` is `Cache-Control: private` with auth disabled too, since the token is honoured in every auth mode.
