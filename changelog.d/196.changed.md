**Env-lock scan covers test modules in files of their own (Maestra fork, maestra-io/nora#196)** — a `#![cfg(test)]` file is scanned with the env readers of the file that declares it (`dir.rs`, `dir/mod.rs`, `main.rs` for `main_tests/`), so a test there that calls `validate()` or `apply_env_overrides()` without `env_lock()` is still caught after R4-T12 moves its module out. Test-only change.
