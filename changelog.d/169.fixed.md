**`namespace_scope` matching no longer slows down with the number of `**` segments (#169)** — the matcher behind OIDC `namespace_scope` tried every split of the artifact path for every `**` in a pattern: eight `**` against a 41-segment path took 14 s per write. It now costs (pattern segments) x (path segments) comparisons. Patterns in use (`myorg/**`) were never slow; the answers are unchanged.
