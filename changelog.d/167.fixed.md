**A cache hit no longer restarts the quarantine clock of a long-cached package (Maestra fork, maestra-io/nora#167)** — the ledger forgets a digest 90 days after its first sight, and the NuGet, PyPI and npm cache-hit paths recorded a digest without a record as first seen now: in `enforce`, every package cached for longer answered 403 for a whole `quarantine_ttl` after each restart. A digest with no record whose cached object NORA wrote more than 90 days ago is now first seen at that write time; inside the 90 days a missing record still counts from now, and a record keeps its own date.
