**Docker: the write scope is checked on the canonical name; repository names follow the OCI grammar (Maestra fork, maestra-io/nora#163)** — an OIDC `namespace_scope` was checked on the name in the URL, so a token scoped to a routing prefix or registry host (`harbor.corp/*`) could write the repository behind it (`payments/api`); the scope is now checked on the name the write is stored under. A write under an upstream's storage namespace, whose keys are that upstream's proxy cache, is 400 `NAME_INVALID`. Names with `--` or `__` (`org/my--image`, `org/a__b`) were refused with 400 and are valid; each path component now follows `[a-z0-9]+((\.|_|__|-+)[a-z0-9]+)*`, so a trailing or mixed separator (`app-`, `a.-b`) is refused.
