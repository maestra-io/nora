**32 more tests stop sleeping on the wall clock (#184)** — after #173, 94 tests still paused for a fixed time. 32 of them now wait for the event or move the clock the code reads: 16 proxy and quarantine tests (Docker, npm, Debian) that slept 200 ms–1 s for a background cache write wait until every write the request started has ended, and the Cargo late-answer test waits until the upstream got the request; 9 lock and race tests (Docker statistics, local storage, the spool cache write, quarantine loading, npm sidecar reads) run on tokio's paused clock; the auth failure tracker, the circuit breaker and the token cache date their stored instants back instead of sleeping 1.1–3 s; three npm tests drop a 1.1 s pause that a zero `metadata_ttl` never needed. The auth tracker test now checks that cleanup removes the entries, which it did not before. No product code changed.
