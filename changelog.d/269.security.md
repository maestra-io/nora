**GitHub release assets are dated by their own upload; unknown releases and API rate limits no longer spend the API budget (audit A064, A065)** — every asset of a release carried the release's `published_at`, so a file added to or re-uploaded in an old release passed `min_release_age` and seeded the digest quarantine as old. An asset NORA has not cached is now dated by the later of the release date and its own `created_at` (a cached copy keeps being served as before; HashiCorp is unchanged). A release the GitHub API does not know is remembered in memory for 5 minutes instead of costing one API call per request; the release-record circuit breaker is keyed by the API host rather than by each release URL; and an upstream 403 carrying `Retry-After` or `x-ratelimit-remaining: 0` is a rate limit (503 with `Retry-After`, a breaker failure) for every proxy format, while any other 403 stays a refusal.
