**maven.google.com artifacts are dated by their `Last-Modified` (#315, issues-maestra#1649)** — only Maven Central gave a release date, so an Android / AndroidX artifact skipped `[curation.maven] min_release_age` and one published today was served and cached. With `server.trust_upstream_dates` a file Central has no date for is now dated by a HEAD on maven.google.com (`dl.google.com/dl/android/maven2`), inside the same `maven.date_lookup_timeout`, and the date also seeds the digest quarantine, so `quarantine = "enforce"` no longer holds a years-old Google artifact on its first fetch. A date names only the upstream that gave it: a file another dated proxy serves is judged by `unknown_date`. `nora_maven_date_lookup_total` gains `source="google"`. Cloudsmith, Confluent and other proxies stay undated.
