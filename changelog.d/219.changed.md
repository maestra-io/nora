**Head-timeout and NuGet hidden-memo tests run on a paused clock (Maestra fork, maestra-io/nora#219)** — the HTTP/1 head timer hands hyper tokio's clock (`Timer::now()`), and the NuGet hidden-versions memo dates its entries on it, so the five head-timeout tests run over an in-memory pipe on a paused clock and assert the exact close instant instead of sleeping about 4.7 s in real time over loopback sockets, and the expired-memo test advances the clock instead of sleeping 1.1 s. Outside tests tokio's clock is the system clock, so the server behaves as before. Tests only.
