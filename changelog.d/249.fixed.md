**apk: a stored index is parsed once per copy, not once per package request (#249)** — every `.apk` GET loaded its index by reading and parsing the whole stored JSON again. Wolfi's (`packages.wolfi.dev/os`, ~55 MB, 121k entries) took a local NORA to 2.3 GB RSS during one apko build of 55 packages; with the parse kept per upstream and storage key and checked against the stored copy's mtime and size, the same build peaks at 373 MB. Concurrent misses share one parse; a refresh records the parse it already has (issues-maestra#1649).
