**One renderer for the five web UI directory pages (Maestra fork, maestra-io/nora#222)** — the raw, Maven, Go, Ansible and CPAN directory browsers were five copies of one page that differed only in layout; `render_dir` now writes all five from a small set of options. Every page's markup is unchanged byte for byte, pinned by snapshots taken from the old renderers. No visible change.
