**deb proxy: name rules hold proxied versions; a permanent hold never forces a rebuild (audit A042, A045)** — the filtered apt proxy held a version only for its release age or an internal namespace, so a blocklist or allowlist rule did not apply to an older, first-sight or `allow`-exempt version: it stayed in the signed `Packages`, could stand in for a held one and downloaded. Every version the curation chain refuses in `enforce` is now held: left out of `Packages` and refused on download with the rule. A hold on a name or rule no longer gives the suite a maturity time, which had rebuilt and re-signed it on every index request. An unfiltered `[deb.proxies]` (no `[curation.deb] min_release_age`) beside a blocklist, allowlist or `internal_namespaces` is a configuration error, since no `.deb` is judged by name there. Add new rules with `curation.mode = "audit"` first: an allowlist without `deb` entries empties every apt index.
