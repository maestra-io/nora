NuGet hosted feed: `dotnet nuget push` (`PUT /nuget/v3/package`, `PackagePublish/2.0.0`), `dotnet nuget delete` as unlist and `POST` relist. Pushed packages are validated (one root `.nuspec`, NuGet-normalized version, 409 on a duplicate id+version), stored under `nuget/hosted/`, and served from the same `/nuget/v3/index.json` ahead of the nuget.org proxy: flat container, registration (inline below 128 versions, paged above) and search. A hosted ID is never proxied upstream. The push key travels as `X-NuGet-ApiKey` and is verified like a Bearer credential (API token or OIDC JWT). Symbol packages (`.snupkg`) are rejected with 400. Before, NuGet was proxy-only.
