**lock-audit Check 5 fails a format without a concurrent publish test (Maestra fork, maestra-io/nora#220)** — the check only printed INFO, and since the test modules moved to `registry/<format>/` it no longer looked where the tests are. maven, pypi and docker gained concurrent publish tests that fail with their handler's publish lock removed (one release deployed at once, one file uploaded at once, one tag pushed at once), npm's existing ones are marked, and the audit now fails when one of the five formats has none.
