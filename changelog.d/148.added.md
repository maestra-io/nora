**OIDC session tokens (issues-maestra#1649)** — `POST /api/oidc/session` exchanges a valid OIDC JWT for an `nrs_` token that lives the provider's new `session_lifetime_secs` (default 0 = off, at most 21600), so a build that writes its credential once outlives a 5-minute GitHub Actions JWT. The session keeps the JWT's role and namespace scope, re-resolved from the running config on every request (a disabled provider or removed rule ends it at the next restart: OIDC config is not reloaded on SIGHUP); an expired JWT within the validation leeway buys none, never mints a session and never manages tokens; accepted as Bearer, Basic password and `X-NuGet-ApiKey`.
