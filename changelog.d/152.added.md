**`Cache-Control: only-if-cached` on Docker manifests (Maestra fork, maestra-io/nora#152)** — a manifest `GET`/`HEAD` with it is answered from NORA's cache only: a cached manifest is served with its quarantine verdict, anything else is `504 MANIFEST_UNKNOWN`, with no upstream request and no first-seen record. Before, asking for a digest NORA had not cached fetched it and started its quarantine clock, so a probe dated the image itself; the github-actions `base-images` PR check reads the verdict this way (issues-maestra#1649).
