**Helm chart repository proxy (Maestra fork, maestra-io/nora#101)** — a `helm` registry type proxies classic chart repositories (`index.yaml` + `.tgz`): `[helm.proxies]` maps a path segment to an upstream, served at `/helm/<name>/index.yaml` with every chart URL rewritten to NORA. A chart is fetched only from the URL the cached upstream index names, refused when its sha256 differs from the index `digest`, and the upstream credential goes only to the upstream's own origin. The first-seen digest quarantine (`[curation.helm]`) is the primary control; in `enforce` a held digest is also left out of the index. `min_release_age` by the index `created` applies only to repos listed in `helm.trust_created`, because several upstreams re-stamp `created` on every index rebuild. See docs/helm-proxy.md.
