**npm: a proxied packument is rendered once per stored document (Maestra fork, maestra-io/nora#170)** — the render of a proxied packument or version manifest (links placed on NORA, the `min_release_age` filter, the `install-v1` form) runs once per stored document and form, on the blocking pool; concurrent requests share it and it is kept for 60 s (the response `max-age`) within 128 MiB. A repeated request finds the render by the document's storage pin and does not read the document. Before, every request read the document (39 MB for `vite`), copied it and parsed it two or three times on a runtime worker, and a CI burst starved the runtime. An internal-namespace name still reads its copy on every request.
