**The Terraform network mirror answers only its configured origin hosts; signed download URLs use the `hmac` crate and live 15 minutes (Maestra fork, maestra-io/nora#260)** — every mirrored provider resolves from the one `terraform.proxy` and its cache keys carry no hostname, yet `/terraform/{hostname}/…` answered any hostname with the upstream's provider of the same name. The mirror now answers only the hosts in the new `terraform.mirror_hostnames` (default `["registry.terraform.io"]`, `NORA_TF_MIRROR_HOSTNAMES` comma list, case-insensitive) and returns 404 for any other before curation, cache or upstream are consulted; a client mirroring another host (OpenTofu's default `registry.opentofu.org` included) must list it or keep it out with an `include` filter, as the COMPAT.md snippet now shows. The signed provider-package URLs are computed with the RustCrypto `hmac` crate instead of a hand-written HMAC (same output) and expire after 15 minutes instead of an hour.
