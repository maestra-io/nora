**apk: flat repositories (#132)** — a proxy whose upstream keeps `<arch>/APKINDEX.tar.gz` at its root (Amazon Corretto, `https://apk.corretto.aws`) is served at `/apk/<name>/<arch>/`; before, only `/apk/<name>/<branch>/<repo>/<arch>/` existed, so an image with Corretto's repository could not install through NORA. The client docs now pass the token in `HTTP_AUTH` instead of the repository URL: apk-tools 2.14.6 and older (Alpine 3.21 and older) reject a URL password over about 1 KiB, and a GitHub OIDC token is longer.
