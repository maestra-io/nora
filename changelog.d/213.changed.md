**Cold HashiCorp release archives stream as they download (Maestra fork, maestra-io/nora#213)** — #192 streamed helm, apk and GitHub release misses; the HashiCorp proxy shares that code but kept `stream: false`, so a `terraform` or `vault` archive reached the client only after the whole download ended. A GET is now answered once the first upstream chunk is spooled; curation and the quarantine decide on the sum from `SHA256SUMS` before the fetch, the last byte is held until the whole file matched it, and a mismatch breaks the transfer off and is not cached. A HEAD and a request joining a running fill are fetched whole first, as before.
