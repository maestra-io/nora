**Helm proxy: the upstream's own chart URLs go through the SSRF guard (maestra-io/nora#101 follow-up)** — a chart on the upstream's own origin was fetched with the plain client, so a redirect from it could reach a loopback, private or metadata address. Every chart download now uses the guarded client unless `helm.allow_private_chart_hosts = true`, which an upstream on a private address now needs.
