**An undated Maven Central artifact is judged by `[curation.maven] unknown_date` (Maestra fork, maestra-io/nora#285, audit A070)** — when Central serves a file on a cache miss but its date lookup (HEAD `Last-Modified`, then the search API) gave no date, `unknown_date` now decides before the file is cached: `log` (the default) serves it and counts `nora_curation_unknown_release_date_total{registry="maven"}`, `hold` judges it released now so `min_release_age` refuses it. Before, every failed lookup left the version undated and `min_release_age` skipped it. A file another proxy serves after a Central 404 stays on the quarantine path. An empty search after a failed HEAD now counts as `missing`, not `not_found`, and the search query encodes each coordinate as one Solr phrase.
