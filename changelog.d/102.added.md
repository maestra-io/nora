**Terraform through an authenticated nora (Maestra fork, maestra-io/nora#102)** — provider package URLs in mirror/registry metadata are HMAC-signed (1 h) and the auth layer admits them without credentials, because Terraform never sends the host token for a package download (every install got 401 with auth on). Under `curation.mode = "enforce"` the provider version lists also hide versions younger than the terraform `min_release_age` (registry.terraform.io `/v2` `published-at`), so a constraint resolves to the newest allowed version instead of failing on its 403.
