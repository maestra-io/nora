**apt proxy release-age hold (Maestra fork, maestra-io/nora#131)** — `[curation.deb] min_release_age` serves every `[deb.proxies]` repository from NORA's own indexes: the upstream `InRelease` is verified against `deb.upstream_keyring_dir`, `Packages` drop versions younger than the rule (age = NORA's first sight of the pool file, persisted under `deb/<repo>/.nora-meta/proxy/ledger/`), `Release` is regenerated and signed as `InRelease`/`Release.gpg` with the `[signing]` key, and a held `.deb` is refused. Without the rule the proxies stay verbatim. Release images build with the `deb` feature (issues-maestra#1649).
