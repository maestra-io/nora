**Sub-path base rewrite only on NORA's own pages; NuGet page data out of script source (Maestra fork, maestra-io/nora#263)** — with `public_url` on a sub-path, the link rewrite now acts only on `/`, `/ui`, `/api/ui` and `/api-docs` (the initializer by its exact path) and buffers at most 8 MiB; registry responses (raw files, proxied HTML) are served byte-for-byte with their own length and ETag. Before, any `text/html` or `*/swagger-initializer.js` response was buffered whole and served altered (audit A090). The NuGet package page reads the package id and base URL from html-escaped `data-*` attributes instead of interpolating them into a JS string literal with an HTML encoder (audit B04).
