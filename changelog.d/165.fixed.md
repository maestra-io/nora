**PyPI: mixed uploads are reported, upload fields are capped, more index dialects parse, fewer storage round trips (Maestra fork, maestra-io/nora#165)** — an upload to a project outside `curation.internal_namespaces` while an upstream is configured now logs a `[SECURITY]` WARN and counts in `nora_pypi_mixed_project_uploads_total{upstream_lists}` (its index is merged with the upstream's; behaviour unchanged); the text form fields of an upload are read under an 8 KiB cap instead of buffered whole; the upstream HTML index parser accepts single-quoted and escaped hrefs, a query after the file name and a bare `data-yanked`; an index request runs its three listings together and a proxied download hit costs one HEAD before its GET instead of two.
