**Hosted NuGet retention and repair (Maestra fork, maestra-io/nora#20)** — PR pre-releases (`X.Y.Z-pr.*`) expire after `[nuget] hosted_pr_retention_days` (30, `NORA_NUGET_HOSTED_PR_RETENTION_DAYS`) unless among the `hosted_pr_keep_last` (20, `NORA_NUGET_HOSTED_PR_KEEP_LAST`) newest of their ID, in a periodic pass (retention interval and dry-run) that also sweeps blob dirs no state document names. A byte-identical re-push answers 200 instead of 409. `nora nuget rebuild <id>` rewrites an ID's state document from its stored nuspecs; the server picks it up without a restart. Hosted packages appear in the web UI. A failed hosted index load now answers 503 and retries with backoff.
