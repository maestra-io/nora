**S3 credentials from a directory, re-read as they rotate (Maestra fork, maestra-io/nora#3)** — `[storage] s3_credentials_dir` (`NORA_STORAGE_S3_CREDENTIALS_DIR`) reads `access_key_id`, `secret_access_key` and an optional `session_token` from files, re-read at most every 60 s, keeping the last good credential if a re-read fails. Before, S3 took a static key pair only, so STS-style temporary credentials (session token, short lease, e.g. Cloudflare R2 creds minted by Vault into a Kubernetes Secret) could not be used. Takes precedence over `s3_access_key`/`s3_secret_key`.
