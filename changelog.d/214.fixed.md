**NuGet registration pages curated as their index (Maestra fork, maestra-io/nora#214)** — `registration_index` ran the package-level curation check, `registration_page` did not, so the pages of a package the index refused (403) were still proxied and cached. Both now take the same decision and serve the proxied document through one function; the request headers reach every page lookup, so the bypass token admits a page as it admits its index.
