**R2 edge errors are retried (Maestra fork)** — Cloudflare's edge sometimes answers an R2 request with `409 Conflict` and the body `error code: 1001` for a few seconds. object_store reads every 409 as `AlreadyExists` and does not retry it, so a cached artifact read became a 503 to the client, and a conditional write of a missing object counted as «already there». Object storage calls now retry such an answer up to three times (200/400/800 ms) and never read it as «already exists»; a real conflict, with an S3 XML body, is answered at once as before (packages.maestra.io, 01.11.2026).
