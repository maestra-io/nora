**GitHub Releases proxy (Maestra fork, maestra-io/nora#120)** — a `github` registry type serves release assets of public GitHub repositories at `/github/<owner>/<repo>/releases/download/<tag>/<asset>` (GitHub's own path under `/github`). Each download reads the release record from the GitHub API: `published_at` is the release date for `min_release_age` (package `owner/repo`, version = tag), an asset it does not list is a 404, and a body whose sha256 differs from the asset digest GitHub lists is refused. Downloads go through the SSRF guard with every redirect hop pinned to github.com, the API host and GitHub's asset CDN; the first-seen digest quarantine (`[curation.github]`) holds them like any proxy artifact. See docs/github-releases-proxy.md.
**HashiCorp releases proxy (Maestra fork, maestra-io/nora#120)** — a `hashicorp` registry type serves releases.hashicorp.com at `/hashicorp/<product>/<version>/<file>`: `timestamp_created` from the releases API dates a version for `min_release_age`, the version's `SHA256SUMS` lists every servable file and its sum (unlisted: 404; mismatching body: refused), and the first-seen digest quarantine (`[curation.hashicorp]`) holds files like any proxy artifact. See docs/hashicorp-releases-proxy.md.
