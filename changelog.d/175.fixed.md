**A cache hit no longer restarts the quarantine clock of a long-cached package in any proxy format (Maestra fork, maestra-io/nora#175)** — #167 fixed NuGet, PyPI and npm; the cache hits of cargo, conan, apk, go, gems, helm, ansible, maven, cpan, pub, github/hashicorp releases, terraform and the rpm/deb proxy still recorded a digest without a ledger record as first seen now, so in `enforce` a package cached for more than 90 days answered 403 for a whole `quarantine_ttl` after each restart. They now date such a digest by the write time of its cached object; inside the 90 days a missing record still counts from now, a record keeps its own date, and bytes fetched from the upstream are recorded at the fetch. Also: a Terraform module source download answers 503, not 404, when the stored source address cannot be read. And the CPAN fallbacks that serve a stored distribution after an upstream 404 or failure now pass the quarantine gate: a held digest was served there.
