**Galaxy versions pages hide young collections (Maestra fork)** — with `min_release_age` set for Ansible, `/ansible/.../collections/{ns}/{name}/versions/` drops versions whose `created_at` is younger than the window, so `ansible-galaxy install community.general:>=8.0.0` resolves to the newest mature version instead of a fresh one the tarball gate then refuses with 403. Audit mode and internal namespaces are unchanged, and a `fields`/`exclude_fields` projection is never forwarded upstream (issues-maestra#1649).
