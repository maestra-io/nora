**NuGet hosted feed (maestra-io/nora#1)** — `dotnet nuget push` (`PUT /nuget/v3/package`, `PackagePublish/2.0.0`, spooled to disk, 250 MiB cap), `dotnet nuget delete` as unlist and `POST` relist, served from the same `/nuget/v3/index.json` ahead of the nuget.org proxy: flat container, registration index, pages (any version range) and leaves, and search/autocomplete (hosted hits first with consistent paging, `packageType`, exact `packageid:`, autocomplete `?id=` versions). A hosted ID is never proxied upstream; an internal ID not pushed yet is only kept off nuget.org by `curation.internal_namespaces`. Hosted state lives in memory after one load, so a public package's restore costs no extra storage call. Push credentials: `X-NuGet-ApiKey`, Bearer, or Basic whose password is an `nra_` token or an OIDC JWT (any registry), with OIDC `namespace_scope` matched case-insensitively for NuGet IDs. `.snupkg` is rejected with 400. Before, NuGet was proxy-only.
