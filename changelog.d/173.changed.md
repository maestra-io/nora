**Timer tests run on a paused clock and cache tests wait for the write (#173)** — 23 tests of the supervisor, the maintenance loop, the proxy coalescer, the cleanup scheduler and `/health` slept on the wall clock and asserted exact values afterwards; they now run on tokio's paused clock. 13 proxy tests (GitHub, Helm, Go, APK, Cargo, Terraform, gems) slept 100–200 ms for a background cache write; they now wait until the write has ended. Two tests that failed on a loaded runner are fixed at the cause (a JWT dated from a stale clock read; a time limit that also covered building the server), and the hash-pin test "a read does not wait for an append" now blocks a real append on a FIFO instead of holding the writer lock by hand. No product code changed.
