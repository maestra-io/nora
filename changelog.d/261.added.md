**Per-repository exemption from the docker quarantine for data artifacts (Maestra fork, issues-maestra#1649)** — `[[docker.quarantine_exempt]]` entries (`repository = "<upstream namespace>/<repo>"`, required `reason`) are never held by the docker digest quarantine, under `observe` and `enforce`: their GET/HEAD reads answer `x-nora-quarantine: exempt`, log `Quarantine: repository exempt by policy` and count in `nora_docker_quarantine_exempt_total{repository}`. A sibling repository stays held. Meant for trivy's `trivy-db` / `trivy-java-db` / `trivy-checks`, rebuilt faster than the hold; data artifacts only, never images that run code. A broken entry stops NORA at start.
