**Maestra CI runs what upstream CI runs for `main`, and a release waits for it (#151)** — PRs into `maestra/main` were gated by fmt, clippy, `cargo test`, advisories and the chart only. They now also run the coverage floor and diff coverage (`main.rs` is measured), the coherence scripts, the full `cargo deny check`, the binary against docker, npm, dotnet and uv, the image on three S3 servers, the release panic check, Kani and a one-minute fuzz run per target. `maestra-release.yml` refuses a tag that is not on `maestra/main` and runs all of these on the tag's commit before it pushes the image.
