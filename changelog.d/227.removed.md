**Object store no longer reads pre-#534 `_at_` keys (R4-P11)** — a `get`, `stat`, `pin`, ranged read or delete of a key with `@` that missed under its `%40` key asked the store a second time under the `_at_` encoding written before #534. The prod bucket holds no such key (381,397 objects listed 13.11.2026), so the second request bought nothing on every miss of a scoped npm package or Go module: a key with `@` is now looked up once.
