**RubyGems compact index for Bundler (#141, maestra)** — `/gems/versions` is served, so Bundler and `gem install` (RubyGems >= 3.6) use the compact index instead of the full Marshal index, and `/gems/info/<name>` leaves out versions younger than `[curation.gems] min_release_age` (RubyGems API `created_at`, kept at `gems/dates/<name>.json`). Before, a Gemfile pinned to an old version failed on the 403 of a young gemspec. Both files carry an MD5 `ETag`, which Bundler 1.x requires.
